# Contributing to Maia

Maia doesn't take pull requests: all of its code is written by its maintainer. Bug
reports and ideas are very welcome as issues, and they shape what gets fixed and built
next.

## Reporting a bug

Use the **Bug report** issue form. It asks for:

- Maia's version (`maia --version`, or About Maia in the command palette) and how you
  installed it.
- Your distribution, desktop, and whether it runs Wayland or X11.
- What you did, what you expected and what happened. Steps that make it happen again
  are worth more than anything else.
- A screenshot or a short recording if it's about how something looks or moves. Check
  it for anything personal first.

If you've found the cause, say where it is and why. Code in an issue is read as a
description of the fix: the fix itself is written from scratch, so please don't expect
it to be merged as you wrote it.

## Ideas

Use the **Idea** issue form. Say what you're trying to do and where Maia gets in the
way, before what the feature should look like. Maia stays small on purpose, so some good
ideas won't fit.

## Using AI

Reports found or written with an AI are welcome. They use the **AI bug report** form
and follow [AI-CONTRIBUTING.md](AI-CONTRIBUTING.md), which asks for proof of what's
claimed.
